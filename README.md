## The word

**Uhhh** — the sound an agent makes when it has no idea what to do.

## How it works

`main.py` writes exactly `Uhhh` (4 bytes, no trailing newline) to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local runs).

## Run locally

```sh
python3 main.py
```
